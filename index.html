Open Meteo API – Specificafion-based testing

Open-Meteo is a free weather API that provides weather forecasts and historical weather data for locations worldwide. It offers a REST API that can be tested using tools such as Postman.

Test scenario

Test API of Open-Meteo web application for location coordinates

API documentation about coordinates: parameter:latitude, longitude Format:Floating point Required parameter:Yes Description:Geographical WGS84 coordinates of the location. Multiple coordinates can be comma separated. E.g. &latitude=52.52,48.85&longitude=13.41,2.35. To return data for multiple locations the JSON output changes to a list of structures. CSV and XLSX formats add a column location_id. For North and South America locations use negative longitudes, because they lie west of Greenwich. There are other parameters required to be set up: in all test cases, the same values of required parameters were used. No API key required.
