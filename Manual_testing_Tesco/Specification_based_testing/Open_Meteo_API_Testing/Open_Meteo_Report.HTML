1. Test Scenario

Test the Open-Meteo Forecast API for geographical location coordinates.

The API endpoint /v1/forecast accepts geographical coordinates and optional weather variables. The documentation states that latitude and longitude are required parameters, while other parameters are optional.

2. API Documentation

Endpoint: GET https://api.open-meteo.com/v1/forecast

ParameterFormatRequiredDescription
latitude Floating point Yes Geographical WGS84 latitude coordinate. Multiple coordinates can be comma separated.
longitude Floating point Yes Geographical WGS84 longitude coordinate. Multiple coordinates can be comma separated.
hourly String array No A list of weather variables which should be returned.
daily String array No Daily weather variable aggregations.
current String array No Weather variables for current conditions.

No API key is required.

Multiple coordinates can be provided as comma-separated values. The documentation states that for multiple locations the JSON output changes to a list of structures, while CSV and XLSX formats add a location_id column.

5. Test Report Summary

The testing focused on the required geographical coordinate parameters of the Open-Meteo Forecast API. Boundary values, invalid values, missing parameters, integer coordinate values and multiple coordinates were tested.

The API correctly accepted valid latitude and longitude boundary values and rejected values outside the valid coordinate ranges. It also rejected non-numeric coordinate values.

Two potential issues were identified when a required coordinate parameter was omitted. The API correctly returned HTTP 400, but the error message did not explicitly identify which required parameter was missing.

When correct coordinates were provided, the response contained location-related metadata such as timezone and elevation. No weather variables were requested in this test scenario, therefore no weather data were returned.

The response also reported the location's calculated elevation.

The precision of the location coordinates should be evaluated in a separate test scenario.
